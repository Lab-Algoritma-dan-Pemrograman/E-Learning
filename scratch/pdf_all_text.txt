2.1. Struktur Penulisan Program Bahasa C 
Contoh Program :  
#include<stdio.h> 
int main(){ 
 
printf("Hello World!");  
return 0; 
} 
Penjelasan : 
Diatas adalah struktur penulisan program dasar bahasa C yang harus dipahami. Dimana 
struktur program dibagi menjadi dua bagian utama: yaitu, bagian #include dan bagian 
fungsi int main(). 
1. Bagian include 
 
• #include adalah bagian yang berfungsi untuk mengimpor fungsi tertentu yang 
sudah didefinisikan pada header file. Header file merupakan file yang berisi 
kumpulan kumpulan fungsi, perintah, dan definisi. 
• Pada contoh diatas kita mengimpor header file <stdio.h> dimana file ini berisi 
deklarasi fungsi dasar untuk membuat program, seperti printf() untuk 
menampilkan output ke layar dan scanf() untuk membaca input yang masuk 
kedalam program. Adapun header file lain seperti <string.h> dan <math.h>. 
• Kita juga dapat membuat header file sendiri. Hal ini sangat berguna jika kita 
mempunyai fungsi atau kode yang sering dipakai di banyak program. Daripada kita 
menulis ulang terus-menerus, lebih baik kita simpan di file header buatan sendiri. 
Kita dapat menuliskannya dengan  #include<namafile.h>.

2. Bagian fungsi int main 
• Fungsi int main() merupakan fungsi utama yang akan dieksekusi pertama kali 
saat program dijalankan. Dimana bagian didalam fungsi main ini adalah statement1, 
statement adalah perintah-perintah atau fungsi melakukan sesuatu. 
• Tanda buka kurung kurawal ({) dan tutup kurung kurawal (}) merupakan fungsi 
untuk mengelompokkan statement, ini disebut dengan aturan penulisan kode blok. 
• Contoh diatas adalah printf(“Hello World!”); artinya kita memerintah 
computer untuk mencetak teks Hello World! ke executable2. 
• Perintah return 0 berhubungan dengan fungsi int main(). Dengan perintah 
return 0 akan menutup fungsi int main() yang sekaligus mengakhiri kode 
program bahasa C.  
Setiap statement dalam program C wajib diakhiri dengan titik koma (;) jika tidak  maka 
program akan error.

angka bulat, angka pecahan, atau berupa karakter, dan sebagainya. Pada Bahasa C 
terdapat 6 tipe data dasar di dalam bahasa pemrograman C.

2.3. Deklarasi Variabel 
Variabel adalah suatu pengenal (identifier) yang digunakan untuk mewakili suatu nilai 
tertentu didalam proses program. Variabel digunakan bila Anda ingin bekerja dengan data 
yang dapat berubah-ubah dari waktu ke waktu dan data tersebut  ingin ditempatkan pada 
lokasi memori yang sama. Variabel dapat kita andaikan sebagai sebuah tempat 
penampungan data, nilai variabel dapat berubah – ubah pada  saat program dijalankan. 
Format pendeklarasian variabel : 
Tipe_data  Nama_variabel   = <nilai> 
Contoh : 
#include <stdio.h> 
int main () { 
int angka = 
10;  
char karakter = 
‘A’;  
float pecahan = 
2.50;  
return 0; 
} 
Penjelasan:  
• int angka akan membuat variable bernama “angka” dengan tipe data interger 
yang hanya bisa diisi dengan bilangan angka bulat.  
• char karakter akan membuat variabel bernama “karakter” bertipe char, 
sehingga hanya bisa menampung karakter.  
• float pecahan akan membuat variabel bernama “pecahan” bertipe data float 
yang hanya bisa diisi dengan angka pecahan. 
Nama_variabel dapat ditentukan sendiri oleh pemrogram dengan aturan sebagai 
berikut : 
• Terdiri dari gabungan huruf dan angka dengan karakter pertama harus berupa huruf. 
Bahasa C bersifat case-sensitive artinya huruf besar dan kecil dianggap berbeda. 
• Tidak boleh mengandung spasi. Jika ingin memisahkan 2 kata maka kita dapat 
menggunakan simbol underscore/garis bawah ( _ ) 
• Tidak boleh mengandung simbol-simbol khusus. Yang termasuk symbol khusus yang 
tidak diperbolehkan antara lain: $, ?, %, #, !, &, *, ( , ), -, +, =  dan sebagainya . 
• Panjangnya bebas, tetapi hanya 32 karakter pertama yang terpakai.

• scanf()

Fungsi pustaka scanf() digunakan untuk menginput data berupa data numeric, 
karakter dan string secara terformat. Hal-hal yang perlu diperhatikan dalam pemakain 
fungsi scanf() : 
1. Fungsi scanf() memakai penentu format. 
2. Fungsi scanf() memberi pergantian baris secara otomatis. 
3. Variabelnya harus menggunakan operator alamat &. 
Kode penentu format : 
• %c 
 
: Membaca sebuah karakter 
• %s 
 
: Membaca kumpulan karakter 
• %i, %d 
: Membaca sebuah bilangan bulat (integer) 
• %f, %lf 
: Membaca sebuah bilangan pecahan (real) 
• %o 
 
: Membaca sebuah bilangan octal 
• %x 
 
: Membaca sebuah bilangan heksadesimal 
• %[^\n] 
: Membaca semua karakter sampai ditemukan enter (baris baru) 
*Note: Perlu diingat jika penggunaan dua scanf("%[^\n]", nama_variabel) digunakan 
secara berturut turut maka hanya fungsi input scanf() pertama saja yang hanya terbaca 
sementara input scanf() kedua dianggap sebagai input kosong. Solusinya gunakan 
fungsi getchar() untuk membuang baris baru sebelum input kedua. 
Contoh: 
#include <stdio.h> 
int main() { 
    char nama[50], jurusan[50]; 
    printf("Masukan nama : "); 
    scanf("%[^\n]", &nama); 
    getchar(); // untuk membuang baris baru sebelum input selanjutnya 
    printf("Masukan jurusan : "); 
    scanf("%[^\n]", &jurusan); 
 
    printf("Nama    : %s\n", nama); 
    printf("Jurusan : %s\n", jurusan); 
    return 0; 
}

2.9. Flowchart 
Flowchart atau Bagan alir adalah bagan (chart) yang menunjukkan alir (flow) di dalam 
program atau prosedur sistem secara logika yang digunakan terutama untuk alat bantu 
komunikasi dan untuk dokumentasi. 
2.9.1.  Aturan Penulisan Flowchart 
Hal-hal yang perlu diperhatikan pada penulisan flowchart : 
1. Flowchart dimulai dari atas ke bawah. 
2. Intruksi dalam bagan alir harus jelas dengan menggunakan kata kerja dan 
memiliki alur data yang rinci dan jelas. 
3. Dimulai dengan awal dan diakhiri dengan akhir. 
4. Harus memiliki input dan output. 
5. Menggunakan penghubung atau flow direction symbol untuk instruksi yang 
terpotong.

2.9.2.   Struktur Penulisan Flowchart

• End :  
Mengakhiri kegiatan pengolahan program.

• Struktur sequence/sederhana

• Struktur branching 
Merupakan flowchart dengan struktur percabangan yang digunakan untuk 
menyeleksi kondisi dan menentukan pilihan proses selanjutnya.

2.2. Perulangan 
Perulangan (looping) adalah suatu pernyataan yang berfungsi untuk mengulang proses 
sesuai dengan yang diinginkan. Banyaknya perhitungan atau pekerjaan berulang sampai 
sebuah kondisi yang tercapai, membuat perulangan menjadi bagian penting dalam 
pemrograman karena dengan adanya perulangan, pembuat program tidak perlu menulis 
kode program sebanyak perulangan yang diinginkan. perulangan mempunyai beberapa 
bagian yang harus dipenuhi yaitu: 
• Inisialisasi adalah menetapkan nilai awal variabel sebelum memulai perulangan. 
• Kondisi adalah syarat yang dicek setiap iterasi; ketika terpenuhi (false), perulangan 
berhenti. 
• Step adalah perubahan nilai variabel di akhir tiap iterasi (misal i++ atau i--) agar 
mendekati kondisi berhenti. 
 
2.2.1. Perulangan while 
Perulangan while merupakan struktur perulangan dimana kondisinya diperiksa 
sebelum statemen, dan akan terus berjalan selama kondisi yang dihasilkan dalam 
perulangan tersebut masih bernilai true (benar). 
Contoh Kode Program while: 
#include <stdio.h>  
int main()  
{ 
    int angka = 1;          // Inisialisasi variabel angka dengan 1 
    while (angka <= 10) { 
    printf("%d\n", angka);      // Mencetak nilai angka 
    angka++;            // Menambah nilai angka dengan 1 
    } 
    return 0; 
}
